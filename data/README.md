# Input data

Put `Tableaux_final_analyses_pour_R.xlsx` here.
This file corresponds to Supplementary Table S1 of the manuscript (raw VITEK 2 and reference MICs, interpretations, species, Enterobacterales groups, phenotypes, resistomes).

Generated folders (created automatically at runtime):
- `tables/`  : Excel exports (error distributions, Fisher OR analyses, McNemar results)
- `figures/` : scattergrams and bar figures (300 dpi)
- `results/` : tabulated results per stratum
