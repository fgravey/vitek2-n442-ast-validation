# Release notes — v1.0.0

## vitek2-n442-ast-validation v1.0.0

Code release accompanying the manuscript:

> Bouland G, Isnard C, Daurel C, Fines-Guyon M, Le Hello S, Malandain D, Gravey F.
> Performance of the VITEK AST-N442 Card for Susceptibility Testing of Hospital-Acquired
> Enterobacterales: High Rates of Very Major Errors for Ertapenem and Nitrofurantoin.
> Microbiology Spectrum (2026). [à compléter : DOI de l'article]

### Contents
- Complete R pipeline for EA/bias/CA/error-rate evaluation per ISO 20776-2:2021, ISO 20776-1:2019 and CLSI M52.
- Exploratory subgroup analyses (Fisher exact, unadjusted p-values; Supplementary Tables S6/S7).
- Figure and supplementary-table generation.

### Data
- Input data file (Supplementary Table S1) available as supplementary material of the manuscript.
- Raw genomic reads: ENA BioProject PRJEB105945 (ERP187096).
